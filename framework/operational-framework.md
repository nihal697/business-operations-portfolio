# Operational Framework

Source: `BOSD Portfolio Nihal Anand.pdf` — summarized here so the repo is searchable without opening the PDF.

## 1. Lead Management

**Flow:** Lead → Qualification → Discovery → Proposal → Negotiation → Decision → Client Setup

**System:** Lead Management System — captures, tracks, manages every lead in real time.

**Business value:** standardized process, complete visibility, reliable handoff.

## 2. Client Setup / Onboarding

**Flow:** Proposal Accepted → Client Onboarding → Information Collection → Access Collection → Workspace Setup → Project Initialization → Ready for Strategy

**System:** Client Onboarding System — collects info, standardizes setup, prepares for execution.

**Business value:** standardized onboarding, complete client records, faster setup, seamless strategy handoff.

## 3. Planning & Production

**Flow:** Strategy → Content Planning → Content Calendar → Content Creation → Internal Review → Client Approval → Ready for Publishing

**System:** Campaign Planning System — aligns strategy, planning, production, approvals.

**Business value:** clear direction, consistent brand messaging, faster production, approval-ready deliverables.

## 4. Performance & Reporting

**Flow:** Publish Content → Monitor Performance → Analyze Results → Prepare Report → Share Insights → Optimize & Improve

**System:** Performance Reporting System — tracks, analyzes, generates actionable reports.

**Business value:** performance visibility, data-driven decisions, continuous improvement, transparent reporting.

## Ecosystem

- **Systems:** the 4 above
- **Business assets:** SOPs, templates, reports, presentations
- **Automation:** Google Apps Script, Workspace automation, client-folder automation
- **Platforms:** Google Workspace, Jira

Principle: *Integrated systems. Practical automation. Consistent operations.*
